Developed using Angular and Spring Boot, enabling users to browse shows, and select seats, with real-time
updates on seat availability and dynamic UI changes.
Implemented a MySQL database to manage and store movie, show, and seat details
Implemented Optimistic Locking for Concurrency handling, to prevent multiple booking of seats, ensuring
data integrity during simultaneous booking attempts.
Email Notifications: Integrated SMTP for email confirmations on booking, Integrated Spring Security for user
authentication
